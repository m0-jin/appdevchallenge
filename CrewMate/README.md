# CrewMate — 함께 타고, 각자의 집까지 🚘

현대자동차그룹 Pleos Connect 앱 개발 공모전 출품을 위한 **차량 디스플레이 + 동승자 휴대폰 화면 인터랙티브 프로토타입**입니다.

> **현재 상태:** HTML/CSS/JavaScript 기반 화면 시연용 데모입니다. 네이티브 Pleos 앱 / APK 또는 실차 연동 제품은 아닙니다.

## 바로 실행하기

- **[화면 시연 HTML 열기](./index.html)** (GitHub에서는 소스 코드가 보입니다. 실제 실행은 아래 GitHub Pages 링크를 사용하세요.)
- GitHub Pages 활성화 후: `https://m0-jin.github.io/appdevchallenge/CrewMate/`

**GitHub Pages 설정 방법**

1. 저장소 **Settings → Pages**로 이동
2. **Build and deployment**에서 **Deploy from a branch** 선택
3. Branch: **main**, Folder: **/(root)** → Save
4. 위 주소로 접속

## 무엇을 시연할 수 있나요?

1. 차량 대시보드에서 동승자 세 명의 귀가 목적지와 하차 순서 확인
2. 동승자 휴대폰 UI에서 목적지 변경 또는 중간 경유지 추가 요청
3. 운전자가 변경 요청을 승인하거나 거절
4. 승인된 경로 반영과 하차 순서 갱신
5. 동승자별 지도·음악 권한 설정
6. 하차 완료 시 동승자 접근 권한 회수 및 공동 세션 종료

## 프로젝트 파일

- `index.html` — 차량용 대시보드, 동승자 휴대폰 UI, 스타일 및 JavaScript를 모두 포함한 단일 실행 파일

외부 패키지, API 키, 서버 없이 동작하도록 구성했습니다. 동일 브라우저 내부 시연을 위한 데모 데이터 기반이며, 실제 서로 다른 스마트폰 간 실시간 연결은 제공하지 않습니다.

## 현재 구현의 범위와 한계

- 지도 화면 및 하차 순서는 **직선거리 기반 개념 시연**입니다. 실제 도로 경로, 도착 예정 시간, 내비게이션을 제공하지 않습니다.
- 운전자/동승자 간 상호작용은 **웹 시뮬레이션**입니다. QR 실제 연결, BLE 감지, 서버 통신, 실차 제어는 아직 없습니다.
- 음악 메뉴는 공동 대기열의 UX 시연이며 실제 음악을 재생하지 않습니다.
- 실제 Pleos NaviHelper SDK 연동·Android APK 빌드·권한 정책 검증은 후속 개발 범위입니다.
